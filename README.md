# Customer Segmentation Project

## Objective
Segment customers based on annual income and spending score using K-Means Clustering.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-Learn

## Features
- Data Analysis
- Elbow Method
- K-Means Clustering
- Customer Segment Visualization

## Outcome
Customers were grouped into 5 meaningful segments for business insights.# Customer-Segmentation-Project
